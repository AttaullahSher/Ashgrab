    How it works

    Ashgrab runs entirely in your browser and asks an open-source cobalt server to fetch the file. If a link fails, it automatically retries with different settings and different servers until one delivers.

    Privacy

    No account, no tracking, no analytics, no cookies. Nothing you paste is stored on any server — your recent list lives only in this browser and you can clear it anytime.

    Run your own server

    Public servers get busy and rate-limited. Set up your own in 2 minutes and paste its address in settings — your grabs then always work, at full speed.

    Fair use

    Download only what you have the right to download — your own uploads, licensed material, or content whose license permits it. Respect each platform's terms and creators' copyright.

      Run your own

      Reliable, unlimited, private. Needs any small VPS with Docker:

      docker run -d --name cobalt \
  -p 9000:9000 \
  -e API_URL="https://cobalt.yourdomain.com/" \
  --restart unless-stopped \
  ghcr.io/imputnet/cobalt:11

      Put it behind HTTPS, then paste the address above. Full guide: run-an-instance.md
