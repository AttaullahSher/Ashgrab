    No account, no tracking, nothing stored. Snagr runs in your browser and asks a cobalt server to fetch the file. If a link fails, it automatically retries with different settings and different servers.

    Public servers get rate-limited and go down. Run your own in 2 minutes for links that always work — then paste its address in settings.

    Download only what you have the right to download. Respect each platform's terms and the creator's copyright.

      Run your own

      Reliable, unlimited, private. Needs any small VPS with Docker:

      docker run -d --name cobalt \
  -p 9000:9000 \
  -e API_URL="https://cobalt.yourdomain.com/" \
  --restart unless-stopped \
  ghcr.io/imputnet/cobalt:11

      Put it behind HTTPS, then paste the address above. Full guide: run-an-instance.md
